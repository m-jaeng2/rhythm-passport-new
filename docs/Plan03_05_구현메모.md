# Plan 03~05 구현 메모

## Plan 03. 모션 입력 및 판정

### 현재 MVP 입력 방식
- 실제 카메라 연동 전까지는 키보드 디버그 입력으로 플레이 가능하도록 구성했다.
- `1` : `RaiseBothHands`
- `2` : `ReachLeft`
- `3` : `ReachRight`

### 시작 자세 기준
- 앉은 자세에서 상체가 정면을 향한 상태를 기본값으로 간주한다.
- Calibration 단계에서 세 가지 동작을 한 번씩 확인하면 플레이 가능 상태로 전환한다.

### 판정 기준
- 현재 목표 동작과 동일한 입력이면 성공
- 다른 동작이 들어오면 실패
- 입력 후 짧은 쿨다운 동안의 중복 입력은 무시
- 제한 시간 안에 입력이 없으면 실패 후 다음 목표로 전환

### 외부 연동 확장 포인트
- `IMotionInputSource`를 통해 실제 MediaPipe 기반 입력 소스로 교체 가능
- `MotionInputFrame` 구조를 유지하면 게임 로직을 크게 바꾸지 않고 연동 가능

## Plan 04. Calibration

### 구현 내용
- 별도 씬에서 좌식 사용 전 준비 단계를 제공
- 세 동작을 한 번씩 확인할 때까지 시작을 잠금
- 완료 후 `Enter`로 `Gameplay` 씬 이동

### 사용자 안내 흐름
- 정면 자세 유지 안내
- 입력별 동작 확인 상태 표시
- 실패 대신 재안내 중심 메시지 사용

## Plan 05. Gameplay

### 메인 게임 규칙
- 무작위로 제시되는 목표 동작을 제한 시간 안에 수행하는 반응형 미니게임

### 조작
- `1 / 2 / 3` : 동작 수행
- `P` : 일시정지
- `Esc` : 세션 중단

### 결과 처리
- 성공 시 점수와 콤보 증가
- 실패 시 콤보 초기화
- 세션 종료 또는 중단 시 `Result` 씬에서 요약 표시

### 현재 구현 범위
- Title > Calibration > Gameplay > Result 흐름
- 세션 타이머
- 목표 동작 갱신
- 성공/실패 피드백
- 결과 요약 표시
