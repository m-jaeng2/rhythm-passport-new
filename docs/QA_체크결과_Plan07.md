# QA 체크 결과 - Plan 07

## 확인 항목
- 입력 인터페이스 추상화 완료
- Debug 입력과 WebSocket 입력 교체 구조 반영
- 외부 수신 포맷 초안 문서화 완료
- 1920 x 1080 기준 HUD/결과 패널 배치 반영
- Orthographic 카메라 기준 유지 확인

## 수동 검증 기준
- Title에서 `F1`, `F2` 전환 시 입력 소스 상태 문구 확인
- Calibration에서 완료 체크가 정상 반영되는지 확인
- Gameplay에서 진행 바와 상태 뱃지가 정상 표시되는지 확인
- Result에서 점수, 성공/실패 횟수, 플레이 시간이 표시되는지 확인

## 남은 실기 검증
- 실제 MediaPipe 송신기에서 WebSocket URL로 메시지 발행
- 흔들림이 큰 환경에서 오입력 빈도 측정
- 장시간 플레이 시 피로도와 UI 가독성 확인
