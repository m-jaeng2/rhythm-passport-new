# Unity MVP 구조 설계

## 범위
- 현재 MVP는 웹 빌드가 아닌 Unity 단일 실행 환경을 기준으로 한다.
- 기준 해상도는 `1920 x 1080`이다.
- 모든 기본 씬 카메라는 `Orthographic` 기준으로 운용한다.

## MVP 범위
- 앉은 자세 기반 모션 게임 1종 구현
- 기본 동작 3종 판정
- Calibration > Gameplay > Result 기본 루프 구성
- 실제 모션 인식 전에도 테스트 가능한 디버그 입력 제공

## 씬 흐름
1. `Boot`
   - 공통 시스템 초기화
   - 전역 설정 유지
   - 첫 진입 씬 라우팅
2. `Title`
   - 게임 시작 진입점
   - 향후 사용자 선택, 튜토리얼 진입 추가 가능
3. `Calibration`
   - 좌식 자세 확인
   - 카메라 프레이밍 및 준비 상태 확인
4. `Gameplay`
   - 메인 게임 루프 실행
   - 동작 판정, 점수, 콤보 처리
5. `Result`
   - 세션 결과 요약
   - 재시작 또는 타이틀 복귀

## 게임 세션 상태
- `Idle`: 시작 전 대기
- `Calibrating`: 자세 맞춤
- `Ready`: 시작 가능
- `Playing`: 게임 진행
- `Paused`: 일시정지
- `Completed`: 정상 종료
- `Aborted`: 중도 종료

## 입력 계층 분리
- `IMotionInputSource`
  - 입력 공급자 인터페이스
  - 실제 인식 입력과 디버그 입력을 같은 계약으로 처리
- `DebugMotionInputSource`
  - 키보드 기반 테스트 입력
  - 실제 인식 연결 전 프로토타입 플레이 가능
- 게임 로직
  - 입력 원본이 아니라 정규화된 액션 이벤트만 소비

## 우선 동작 3종
- `RaiseBothHands`
- `ReachLeft`
- `ReachRight`

## 성공/실패/재시도 기준
- 성공
  - 지정 동작이 허용 시간 내 감지됨
- 실패
  - 시간 초과 또는 다른 동작 반복
- 재시도
  - 실패 즉시 큰 패널티를 주지 않고 다음 입력 기회를 제공

## 점수 시스템 초안
- 기본 성공 점수: `100`
- 연속 성공 시 콤보 증가
- 콤보에 따라 추가 보너스 적용 가능
- 초기 MVP는 복잡한 등급보다 명확한 성공 횟수와 총점을 우선

## ScriptableObject 사용 결정
- 세션 길이, 점수, 콤보 보정값, 동작 판정 시간 등은 `ScriptableObject`로 분리한다.
- 하드코딩을 줄이고 기획 조정을 쉽게 만든다.

## 공통 데이터 모델
- `MotionActionType`
  - 게임이 인식하는 추상 동작 종류
- `MotionInputFrame`
  - 입력 프레임 시점의 동작, 신뢰도, 타임스탬프
- `GameSessionConfig`
  - 세션 시간, 기본 점수, 콤보 설정

## UI 기준
- Canvas Scaler 기준 해상도는 `1920 x 1080`
- 큰 글씨와 단순한 버튼 구조 사용
- 상태 피드백은 색상만이 아니라 텍스트와 아이콘도 함께 사용

## QA 기준
- 1920 x 1080 해상도에서 UI 배치 확인
- 모든 기본 씬에서 Orthographic 카메라 유지 확인
- 디버그 입력만으로 Title > Calibration > Gameplay > Result 루프 점검
- 우선 동작 3종에 대한 점수 반영 흐름 점검
