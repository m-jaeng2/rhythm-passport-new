# 게임 구조 설계

## 목표
- 게임 흐름과 시스템 책임을 분리해 유지보수 가능한 구조를 만든다.

## 체크리스트
- [x] 전체 씬 흐름 정의
- [x] `Boot`, `Title`, `Calibration`, `Gameplay`, `Result` 역할 정의
- [x] 게임 세션 상태 정의
- [x] 입력 처리 계층과 게임 로직 계층 분리
- [x] 점수 시스템 구조 정의
- [x] 성공/실패/재시도 규칙 정의
- [x] ScriptableObject 사용 여부 결정
- [x] 공통 데이터 모델 초안 작성

## 산출물
- 씬 흐름도
- 시스템 책임 정의
- 상태 전이 기준
