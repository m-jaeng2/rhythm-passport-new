# 전체 로드맵

## 목적
- Unity 기반 헬스케어 모션 게임 MVP를 단계적으로 개발한다.
- 앉은 자세 중심의 안전한 운동 게임을 우선 완성한다.

## 작업 단계
1. 프로젝트 기준 확정
2. Unity 기본 환경 구축
3. 좌식 모션 입력/판정 구조 설계
4. Calibration 흐름 구현
5. 메인 게임 루프 구현
6. 결과 및 피드백 화면 구현
7. 외부 인식 연동 대비 구조 정리
8. QA 및 튜닝
